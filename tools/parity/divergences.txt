# Declared differences between the baseline/reference outputs and the Rust runtime.
#
# SPDX-License-Identifier: Apache-2.0
#
# A difference between compared runtimes is a FAILURE until somebody decides
# it is not. The decision goes here, with its reason, and the file is in the
# tree so that the reason is REVIEWED rather than remembered.
#
# A declared divergence is still printed on every run, with the diff. It
# does not fail the run, because a difference that was decided on is not an
# accident -- but a declared divergence that nobody reads is an accident
# wearing a label, and the print is what stops that.
#
# THE FORMAT
#
# One case id, a colon, and the reason. The reason is the whole point: a
# case id with no reason is a suppression.
#
# WHAT DOES NOT BELONG HERE
#
# * A difference that has not been decided on. That is a failure, and it
#   belongs in the report.
# * A difference caused by the ENVIRONMENT -- a missing model, a missing
#   design set. Those are skips, not divergences: they say that the case
#   could not be run, which is a different statement from "the two
#   runtimes differ here, on purpose".

sub/add: the reference baseline aborts in a libc/stdio path on this machine
         when the network path runs, while this runtime refuses cleanly.
         A crash is not a contract: it says what the process did, not what
         the runtime means.

sub/list: the reference baseline ignores `--root` and reports the tree its own
          binary lives in; this runtime honours it. The case may still compare
          equal when both default roots hold the same containers, but the two
          runtimes would answer differently when the trees held different
          models.

error/dev-unknown-generation: the reference baseline does not validate the
          generation name explicitly. An unknown value may be carried into the
          design search and fail indirectly. This runtime rejects an unknown
          generation by name.

http/root: the reference server hardcodes fields that can be incorrect for the
           actual serving path/device on this machine. This runtime reports the
           observed model/backend information. Other body fields (including the
           vector) are compared where applicable.

http/health: same class of difference as `http/root` in the reported model/backend
             fields.

http/models: same class of difference as `http/root` in the reported model/backend
             fields.

http/embeddings: same class of difference as `http/root` in the reported
                 model/backend fields. The vector payload is byte-identical in
                 the compared form.

http/wrong-family-labels: same class of difference as `http/root` in the banner
                          metadata. The wrong-family 404 body that names the
                          correct endpoint is compared separately.

error/unknown-model: this runtime's "not installed / not known" refusal also
                     mentions the `weights/<family>/<model>/` layout as a valid
                     location for a packed container. The refusal is the same in
                     kind and lists the same known models; only the location
                     hint is more specific.
